# EP.02 · PS5 为什么难破解？

从 PS5 安全角度解释密钥隔离、权限边界、漏洞链与防御迭代。面向普通玩家，不包含漏洞利用步骤、解密密钥、破解工具或游戏资源。

逐场完整口播稿以 [episode.json](episode.json) 的 `narration` 为唯一来源；生成的字幕保留句级时间轴。

| 场景 | 画面与要点 |
|---|---|
| 不是一把锁 | 主机移向保险箱；机器归你，不代表全部安全权限归普通程序 |
| 三件不同的事 | 加密、签名、许可证分开，不把“文件下载完成”等同于获得授权 |
| 硬件信任边界 | 普通程序与安全机制隔离；明确标注概念图，不虚构内部密钥路线 |
| 一层失守不等于全失守 | 应用、内核、Hypervisor 三层逐个入场 |
| 攻击者找的是漏洞链 | 入口、权限提升、更深防线；红叉阻断“崩溃即成功”的误解 |
| 真实研究案例 | Byepervisor 系列；局部突破必须附带适用条件和完成范围 |
| 导出不等于移植 | 内容可读、适配环境、正确运行三步，不用显卡性能代替兼容性 |
| 防御方也在迭代 | 修补、减少暴露、敏感检查；给普通玩家可执行的防护建议 |
| AI 加速，不等于魔法 | 分析线索、稳定突破、长期可玩是不同成果；不预测破解期限 |
| 三个不等于 | 文件不等于授权，局部突破不等于全机失守，导出不等于 PC 可玩 |
