01:23 签名、证书、时间戳怎么写进 PDF
01:47 原件绿勾，改字红叉
02:07 三个坑：截图、改字、证书过期
02:32 记住三看

用星河科技/云海供应链的采购合同举例：金额从 100 万改成 900 万，SHA-256 从 6364… 变成 0e72…，签名立刻对不上。图片本身不是可靠的电子签名，但可以是证据线索；法院会看原始 PDF、CA 证书、时间戳、签署日志，必要时做鉴定。

## 置顶评论

```
补充两个最容易踩的点：
1. 图片/截图/打印件本身不是可靠电子签名，但可以是证据线索。法院会看原始 PDF、CA 证书、时间戳、签署日志，必要时做司法鉴定。打印件别丢，原始电子文件更重要。
2. 绿色对勾的前提是证书在阅读器的信任列表里；国内 CA 的根证书不一定在 Adobe 默认列表，显示“有效性未知”不等于假签名。

脚本/配音/HTML 已开源，仓库里还有事实核对笔记：
https://github.com/makewheels/three-minute-class
```
